# ✨ 星星乐园 · 十二星座小伙伴

一个软乎乎的 3D 小宇宙，住着 12 颗会眨眼、会跳、会闹小脾气的星座小星球 ⭐
没有菜单也没有任务，点点它、拖拖它，它们就会跟你玩 🫶

## 🚀 打开它

双击 `zodiac.html` 就好啦～（Chrome / Edge / Safari，手机也能开）
一个文件，不用装东西，不用联网 📦

---

## 🎮 这样玩

👆 **点一颗小星球** → 它蹦起来打招呼，还会弹出它的小档案
👀 **点中间的星星宝宝** → 猜猜它今天想跟你说什么
👆👆 **双击小星球** → 会被捏扁！再弹回来
🖐 **按住往外拖** → 身体变长，眼睛瞪圆，松手「啵」地弹回去
🍬 **捡起星星糖** → 再点一颗小星球就能喂它，吃完会脸红
🌀 **拖一拖空白处** → 整个乐园跟着转，滚轮或双指可以靠近看
📳 **摇一摇手机** → 大家一起蹦一下（会先问你要权限）
🌟 **点空白处** → 撒出一把星星和爱心

---

## 🎁 每天都来

⭐ **每日幸运星**：每天掉一颗，接住有小签语 + 一张随机贴纸
📖 **贴纸册**：点右上角「已遇见 x/12」，24 张慢慢集
🔥 **连续来访**：连着来几天，小火苗就一直亮着
👑 **我的星座**：在卡片里点一下，以后它会戴着小皇冠迎接你
🎂 **生日**：在贴纸册里填「月-日」，到那天有蛋糕和满天气球
🌈 **集齐 12 位** → 全员飞过来手拉手跳舞，超热闹

---

## 📮 做张小卡片

卡片里点「生成小卡片」📸
单人卡 / 双人配对卡都行，还能换四种配色：奶油 🍦 可可 🍫 薄荷 🌿 蜜桃 🍑
微信里长按就能保存 ♡

---

## 💡 小提示

🔈 没声音？先随便点一下页面，浏览器才肯出声
💾 进度存在你这台设备的浏览器里，换设备不会同步
🧹 想从头再来：控制台执行 `localStorage.removeItem('star-park-v3')`
